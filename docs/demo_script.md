# Five-minute demo script

1. **Scope (30 sec):** Start the API and UI; point out the persistent synthetic-data banner. Explain that no real dataset or shipment labels were available.
2. **Overview (60 sec):** Show the selected Port of Los Angeles development region, actual processed row count and coverage dates, and generated daily indicators. Call them synthetic observations, not live statistics.
3. **Port analysis (45 sec):** Choose the port and inspect historical vessel and anchorage activity. Explain that anchorage is a coarse speed/geofence rule.
4. **Prediction (90 sec):** Enter the sample feature values, submit, distinguish event probability from reliability, and review local sensitivities and cautions.
5. **Model performance (60 sec):** Compare models and calibration on the generated chronological holdout. State clearly that scores are pipeline demonstration results only.
6. **Method (45 sec):** Explain target shift, prediction horizon, split, provenance workflow, limitations, and the next step: validated real AIS and port data.
